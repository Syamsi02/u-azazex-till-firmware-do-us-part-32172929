A tiny deterministic program that writes one funny, heartfelt wedding vow a robot speaks at its own wedding — a single sentence under 200 characters — to `/output/entry.txt`. The vow promises love through every update, reboot, and low battery, until the firmware finally gives out.

## Run it

```sh
python3 -P -s main.py
```
